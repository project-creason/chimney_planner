Price sheet import

Load a distributor's part numbers and prices for the planner.

Back to the planner

Sign in

Use the admin password set on the server (ADMIN_PASSWORD in Vercel).

1 · Customer

Choose the retailer or distributor that these prices belong to, or add a new one. Each customer has its own part numbers, its own price lists and a private planner link that shows plans at its prices.

A new customer's link is shown only once, right after its first import, so copy it then and send it to the customer privately.

2 · Price sheet

Upload the sheet exactly as you received it. It can be an Excel (.xlsx) or CSV file with any column names, and it can have title rows above the headers.

Rows for other products are fine. Parts in our catalog are used right away, and the other rows are kept so their prices are ready when their product line is added. The file itself is not stored, only its rows.

3 · Columns guessed from the sheet; change any that are wrong

Choose which column holds each kind of information. The highlighted columns in the sample below are the ones that will be used.

  • Manufacturer part number is used to match each row to our catalog. It can be the order number, such as 6DT-48SS, or the stock number. This column is required.
  • Customer part number (SKU) is the customer's own number for the part, and it appears on their plans and orders.
  • Customer price is the price that plans and orders show. Choose the selling price (MSRP or list price) rather than the dealer cost. Prices are rounded to the nearest cent.
  • Customer description replaces our description on their orders when the sheet has its own.
Part numbers with an extra code in front (rarely needed)

Some distributors put their own code in front of the manufacturer's number, for example DUR6DT-48 for Duravent's 6DT-48. If you enter that code here (DUR in this example), it is removed before the rows are matched.

You will rarely need this, because the page detects such codes and offers to ignore them, and names written like DuraVent:6DT-48 are already handled.

4 · Price list

Prices are saved as a named list with the dates when it applies. This lets you load next year's prices ahead of time while keeping the old ones.

Plans use the list that is in effect today. If more than one list is in effect, plans use the one that started most recently. Importing a list with an existing name replaces that list.

5 · Check and import

Check the totals and a few of the rows below. Nothing is saved until you click Import.

Importing adds or updates the customer's part numbers for the matched parts and keeps their other part numbers. It also replaces the named price list. Parts without a price are shown as "no price" on plans.
